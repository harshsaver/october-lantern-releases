# October Lantern — downloads

October Lantern is a small glowing lantern on the edge of your screen that watches every AI coding agent on your Mac (Claude Code, Codex, OpenCode, Pi and more) and lights up when one of them needs you.

## Download

**[Download October Lantern for macOS](https://lantern.october.dev/download/mac)** · **[Windows (preview)](https://lantern.october.dev/download/windows)**

Downloads come from lantern.october.dev, which serves the newest release from this repository. If your network blocks GitHub's file host, use those links rather than the files below.

- macOS 14 Sonoma or later
- Apple silicon and Intel
- Signed with Developer ID and notarized by Apple

Open the DMG and drag **October Lantern** to Applications. Lantern lives on the edge of your screen and in the menu bar.

All versions and release notes are on the [Releases](https://github.com/harshsaver/october-lantern-releases/releases) page.
